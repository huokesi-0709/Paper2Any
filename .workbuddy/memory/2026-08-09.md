# 2026-08-09 工作日志

## 前端启动问题修复（Paper2Any frontend-workflow）

### 问题根因（用户诊断）
WordBuddy Bash 工具运行 Vite 时卡死 = Windows 管道缓冲区死锁：
- `2>&1` 把 stdout+stderr 合并到管道，父进程不持续读取 → 4-8KB 缓冲区写满 → node `write()` 内核级阻塞 → Vite 事件循环冻结，不绑定端口。
- `cd xxx && node xxx` shell 拼接在 Windows 下 cwd 切换不可靠。
- 直接调 `node.exe node_modules/vite/bin/vite.js` 有 ESM/CJS 加载坑。

### 修复清单
1. **package.json**：`dev` 脚本改为 `vite --host 0.0.0.0 --port 3000`（走 npm 入口避开 ESM 坑）；`preview` 同样加 host/port。
2. **删除 `src/App.tsx`**：死代码（main.tsx 只引 NewApp），含 8 个不存在的页面 import + 旧 Sidebar/TopBar props，导致 `tsc` 报错阻断 `npm run build`。
3. **`src/app/components/ApiConfigSection.tsx:135`**：`API_URL_OPTIONS.map((url: string) =>` 补显式类型，消除 implicit any。
4. **`src/vite-env.d.ts`**：`ImportMetaEnv` 补 `VITE_LLM_API_URLS?: string`，根治 `import.meta.env` 类型缺失。

### 验证
- `tsc --noEmit` 退出码 0，无错误。
- `vite build` 此前已通过（1687 modules）。
- 8 个页面 wrapper 文件齐全，barrel 导出正确。
