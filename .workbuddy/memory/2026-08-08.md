## 修复：前端鼠标滚轮无法滚动
- **根因**：app-shell 布局下 `main` 内容区 `<div className="flex-1">` 既无 `overflow-y-auto`，亦无 `min-h-0`。Flexbox 默认 `min-height: auto` 让该子元素随内容膨胀，从而永远无法超过容器高度 → `overflow-y-auto` 滚动条无法触发 → 内容被 `body`/`h-screen` 根容器的 `overflow: hidden` 裁剪，整页无法滚动。
- **修复** (`frontend-workflow/src/App.tsx` line 207)：`<div className="flex-1">` → `<div className="flex-1 min-h-0 overflow-y-auto overflow-x-hidden">`。`min-h-0` 打破 flex `min-height: auto` 约束；`overflow-y-auto` 让主内容区成为滚动容器（header/footer 仍固定不动）。
- **注意**：弹窗模态框中已用的 `flex-1 overflow-hidden` 天然包含 `min-h-0` 效果，故其页面可正常滚动，无需改动。`Image2PptPage` 未挂载在 App 路由，暂不受影响。
- **校验**：`npm run build` exit 0，`tsc` 错误为 0。
