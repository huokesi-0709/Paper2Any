# 2026-08-07

## GPU 驱动约束（重要）
- 本机 NVIDIA 驱动版本 11.7（torch 报 `found version 11070`），而项目要求 CUDA 12.6+（torch cu126 / cu128 运行库）。
- 硬约束：驱动 11.7 → 最高只能用 CUDA 11.7，任何 cu12x 的 torch 在本机 `cuda.is_available()` 均为 False。
- 项目依赖锁死现代栈：`requirements-win-base.txt` → `torch==2.7.1+cu126`；Linux `torch==2.10.0` + `requirements-cu12.txt`（CUDA 12.8 运行库）。
- 降级 torch 到 cu117（退到 torch 2.1）会连锁破坏 transformers 4.57 / accelerate 1.12 / ultralytics / kornia / timm，不可行。
- 结论：本机 GPU 管线唯一干净解法是**升级 NVIDIA 驱动到 ≥ R570（对应 CUDA 12.8）**，升级后现有 conda 环境原样可用，无需重装 torch。
- 用户确认可升级驱动（有管理员权限 + 可重启），选择路线 A。
